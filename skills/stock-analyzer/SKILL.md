# stock-analyzer v1.0.0

A 股深度分析工具，生成价值 + 技术 + 成长 + 财务多维评分报告。

## 功能

- ✅ 价值评分（25 分）— PE/PB/股息率分位
- ✅ 成长评分（25 分）— 营收/净利润增速
- ✅ 财务评分（25 分）— ROE/毛利率/负债率
- ✅ 技术评分（25 分）— 趋势/成交量/支撑阻力
- ✅ 综合评分 + 建仓建议

## 使用方法

```bash
# 单只股票深度分析
uv run python analyze.py --stock 600519.SS

# 多只股票批量分析
uv run python analyze.py --stocks 600519.SS,300750.SZ

# 输出 JSON 格式
uv run python analyze.py --stock 600519.SS --json
```

## 评分标准

### 价值评分（25 分）
| 指标 | 分值 | 评分标准 |
|------|------|----------|
| PE 分位 | 10 分 | <30%:10 分，30-50%:7 分，50-70%:4 分，>70%:1 分 |
| PB 分位 | 10 分 | 同上 |
| 股息率 | 5 分 | >3%:5 分，2-3%:3 分，1-2%:2 分，<1%:0 分 |

### 成长评分（25 分）
| 指标 | 分值 | 评分标准 |
|------|------|----------|
| 营收增速 | 10 分 | >30%:10 分，20-30%:7 分，10-20%:4 分，<10%:1 分 |
| 净利润增速 | 10 分 | 同上 |
| 机构预测 | 5 分 | 买入>10 家:5 分，5-10 家:3 分，<5 家:1 分 |

### 财务评分（25 分）
| 指标 | 分值 | 评分标准 |
|------|------|----------|
| ROE | 10 分 | >20%:10 分，15-20%:7 分，10-15%:4 分，<10%:1 分 |
| 毛利率 | 10 分 | >50%:10 分，30-50%:7 分，20-30%:4 分，<20%:1 分 |
| 负债率 | 5 分 | <30%:5 分，30-50%:3 分，50-70%:2 分，>70%:0 分 |

### 技术评分（25 分）
| 指标 | 分值 | 评分标准 |
|------|------|----------|
| 趋势 | 10 分 | 多头排列:10 分，震荡:5 分，空头:1 分 |
| 成交量 | 10 分 | 放量上涨:10 分，缩量:5 分，放量下跌:1 分 |
| 支撑阻力 | 5 分 | 突破阻力:5 分，区间震荡:3 分，跌破支撑:1 分 |

## 数据源

- 行情数据：东方财富 Push2 API
- 财务数据：东方财富 F10
- 机构评级：东方财富研报

## 限制

- 评分仅供参考，不构成投资建议
- 数据有 15 分钟延迟
